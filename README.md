# Arts of Mahera

**Arts of Mahera** is a handmade business website developed to showcase and manage crochet products, custom gifts.

## Features
- User registration and login
- Product categories and product details
- Shopping cart
- Checkout system
- Order management
- Admin dashboard
- Product management
- Order status tracking

## Technologies Used
- HTML
- CSS
- Bootstrap 5
- JavaScript
- PHP
- MySQL
- XAMPP

## Database
Database name: `arts_of_mahera`

## Project Purpose
This project was developed as a Web Programming project to create an online platform for a handmade business.
